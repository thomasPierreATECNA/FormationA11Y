Structuration de l'information

Thématique 9 du RGAA.

Une page complexe et dont la structure est mal pensée peut être très difficile à comprendre et a utiliser pour certains personnes.

Ici on se concentre sur la manière dont le code source structure le contenu pour qu'il soit compréhensible, tant par les utilisateurs que par les technologies d'assistance (comme les lecteurs d'écran).

Voir les 14 critères

Structuration de l'information

Les titres

Critères 9.1 et 9.2

La structure de titre de la page est primordiale pour hierarchiser l'information. Elle permet à un utilisateur de naviguer dans une page comme on parcourt la table des matières d'un livre.

Il existe 6 niveaux de titres HTML (h1 à h6).
L'ordre des titres doit être logique et cohérent dans une page web.

Les listes

Critère 9.3

Il arrive fréquement que des éléments soient répétés dans une page web, comme par exemple :

  • Des resultats de recherche
  • Des étapes à suivre dans un tunnel d'achat
  • Des caractéristiques d'un produit
  • Des liens de navigation dans un pied de page
  • Etc.

Il est important que ces éléments soient structurés en liste dans le code source, pour que les utilisateurs de lecteurs d'écran puissent comprendre que ces éléments font partie d'un même groupe.

Les lecteurs d'écran ont des commandes pour naviguer de liste en liste, et pour annoncer le nombre d'éléments dans une liste.

Les listes

Il existe plusieurs façons de structurer une liste dans le code source, en fonction du contexte :

Les listes simples

```html
  • élement 1
  • élement 2
  • élement 3
```
  • élement 1
  • élement 2
  • élement 3

Les listes ordonnées

```html
  1. élement 1
  2. élement 2
  3. élement 3
    4. ```
    1. élement 1
    2. élement 2
    3. élement 3

Les listes de description

```html
Élement 1 :
Description de l'élement 1
Élement 2 :
Description de l'élement 2
Élement 3 :
Description de l'élement 3
```

Description de l'élement 1
