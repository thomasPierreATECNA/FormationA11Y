Les scripts

Thématique 7 du RGAA.

La plupart des sites web utilisent JavaScript pour rendre les pages plus interactives et dynamiques. Ces scripts peuvent améliorer l'expérience utilisateur, mais peuvent aussi poser des problèmes d'accessibilité s'ils ne sont pas correctement implémentés.

L'objectif de cette thématique est de s'assurer que les scripts utilisés sur une page web ne créent pas d'obstacles pour les utilisateurs qui n'utilisent pas de souris ou d'écran, ou qui utilisent des technologies d'assistance pour naviguer sur le web.

Voir les 5 critères

Compatibilité des scripts

Critères 7.1 et 7.3

Pour que ce critère soit respecté, les scripts utilisés sur une page web doivent être compatibles avec les technologies d'assistance et les navigateurs utilisés par les personnes en situation de handicap.

Par exemple, si le survol d'un composant d’interface déclenche une action, il faut s'assurer que cette action peut être également déclenchée par d'autres moyens, pour les personnes qui n'utilisent pas de souris ou d'écran.

Les rôles de message

Il existe des rôles ARIA spécifiques pour les messages de status, en fonction de leur nature et de leur importance :

Chacun de ces rôles a des caractéristiques spécifiques en termes de vocalisation et de priorité d'annonce par les lecteurs d'écran, il est donc important de choisir le rôle approprié pour chaque message.

Par exemple, un message avec role="alert" sera vocalisé immédiatement et interrompra la lecture en cours, tandis qu'un message avec role="status" sera vocalisé de manière plus discrète et n'interrompra pas la lecture en cours.
